# Québec Twin – Geospatial Data Preparation

**Project Designer and Developer:** Alireza Adli  
**Institution:** Next-Generation Cities Institute (NGCI), Concordia University

## Overview

This project develops automated geospatial data-cleaning workflows to generate building-level geometric and attribute datasets for the Québec Twin project at Concordia University's Next-Generation Cities Institute (NGCI).

The project is designed and developed by **Alireza Adli**, at the request of NGCI, to support urban building modelling and digital twin applications across Québec.

## Research Foundation

This project builds upon original research by Alireza Adli on geospatial data cleaning, workflow abstraction, and automation for urban building modelling. The underlying methodology is documented in a research manuscript currently being prepared for publication.

## Project Scope

The initial development focuses on three Québec cities:

- **Gatineau**
- **Trois-Rivières**
- **Saint-Jérôme**

The project involves identifying municipality-specific data characteristics, adapting and automating geospatial cleaning workflows, and generating standardized building-level datasets suitable for downstream urban modelling.

The long-term objective is to extend these workflows across the **province of Québec**, establishing a reusable and scalable geospatial data preparation pipeline.
